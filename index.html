CSS

CSS (Cascading Style Sheets) es un lenguaje de hojas de estilo utilizado para describir la presentación de un documento HTML. Permite a los desarrolladores web controlar el diseño, el formato y la apariencia de las páginas web, separando el contenido (HTML) de la presentación (CSS). Con CSS, puedes definir estilos para elementos específicos, como colores, fuentes, márgenes, y mucho más, lo que facilita la creación de sitios web atractivos y consistentes.

Estructura CSS

La estructura básica de un archivo CSS se compone de selectores y declaraciones. Un selector es el elemento HTML al que deseas aplicar estilos, mientras que una declaración consiste en una propiedad y un valor que define cómo se debe presentar ese elemento. Por ejemplo:

        selector {
            propiedad: valor;
        }

En este ejemplo, "selector" es el elemento HTML que deseas estilizar, "propiedad" es la característica que deseas modificar (como color, tamaño de fuente, etc.), y "valor" es el valor específico que deseas asignar a esa propiedad.

Agregar CSS a un documento HTML

Hay tres formas de agregar CSS a un documento HTML:

  1. Hoja de estilo interna: Se define dentro de la etiqueta <style> en el interior de la etiqueta <head>.
  2. Hoja de estilo externa: Se define en un archivo separado con extensión .css y se vincula al documento HTML usando la etiqueta <link>.
  3. Estilos en línea: Se definen directamente en los elementos HTML utilizando el atributo style.

Selectores CSS

Los selectores CSS son patrones utilizados para seleccionar los elementos HTML a los que se aplicarán los estilos. Existen varios tipos de selectores, incluyendo:

  • Selector de tipo: Selecciona elementos por su nombre de etiqueta (por ejemplo, p para párrafos).
  • Selector de clase: Selecciona elementos que tienen una clase específica (por ejemplo, .mi-clase).
  • Selector de ID: Selecciona un elemento único por su ID (por ejemplo, #mi-id).
  • Selector de atributo: Selecciona elementos basados en la presencia o valor de un atributo (por ejemplo, [type="text"] para campos de texto).

  • Selector de descendiente: Selecciona elementos que son descendientes de otro elemento (por ejemplo, div p para párrafos dentro de un div).

La especificidad de los selectores CSS determina qué estilos se aplican a un elemento cuando hay múltiples selectores que coinciden con él. La especificidad se calcula en función de los diferentes tipos de selectores, siendo los selectores de ID los más específicos y los selectores de tipo los menos específicos.

El orden entonces sería el siguiente:

  1. Estilos en línea (más específicos)
  2. Selectores de ID
  3. Selectores de clase, pseudo-clases y atributos
  4. Selectores de tipo (menos específicos)

Propiedades CSS comunes

Algunas de las propiedades CSS más comunes incluyen:

  • color: Define el color del texto.
  • background-color: Define el color de fondo de un elemento.
  • font-size: Define el tamaño de la fuente.
  • margin: Define el espacio alrededor de un elemento.
  • padding: Define el espacio entre el contenido de un elemento y su borde.
  • border: Define el borde de un elemento, incluyendo su ancho, estilo y color.

Box Model

El modelo de caja (Box Model) es un concepto fundamental en CSS que describe cómo se calculan las dimensiones y el espacio de los elementos en una página web. Cada elemento HTML se representa como una caja rectangular que consta de cuatro áreas: contenido, padding, borde y margen.

  • Contenido: Es el área donde se encuentra el contenido real del elemento, como texto o imágenes.
  • Padding: Es el espacio entre el contenido y el borde del elemento. El padding puede ser transparente o tener un color de fondo.
  • Borde: Es la línea que rodea el padding y el contenido. El borde puede tener diferentes estilos (sólido, punteado, etc.) y colores.
  • Margen: Es el espacio entre el borde del elemento y los elementos adyacentes. El margen es completamente transparente.

El modelo de caja es esencial para entender cómo se distribuyen los elementos en una página web y cómo se pueden controlar sus dimensiones y espacios utilizando CSS.

Unidades en CSS

En CSS, se pueden utilizar diferentes unidades para definir tamaños y distancias. Algunas de las unidades más comunes incluyen:

  • px (píxeles): Unidad absoluta que representa un punto en la pantalla. Es la unidad más común para definir tamaños fijos.
  • % (porcentaje): Unidad relativa que representa un porcentaje del tamaño del elemento contenedor. Es útil para diseños fluidos y responsivos.
  • em: Unidad relativa que se basa en el tamaño de la fuente del elemento actual. 1em es igual al tamaño de la fuente del elemento, por lo que es útil para definir tamaños relativos a la fuente.
  • rem: Unidad relativa que se basa en el tamaño de la fuente raíz (generalmente el tamaño de la fuente del elemento <html>). 1rem es igual al tamaño de la fuente raíz, lo que permite una mayor consistencia en los tamaños relativos.

Distribución de elementos

CSS ofrece varias técnicas para distribuir elementos en una página web, incluyendo:

  • Flexbox: Un modelo de diseño unidimensional que permite distribuir elementos en una sola dirección (horizontal o vertical) y controlar su alineación y espacio entre ellos.
  • Grid: Un modelo de diseño bidimensional que permite crear diseños complejos con filas y columnas, facilitando la distribución de elementos en ambas direcciones.
  • Float: Una técnica más antigua que permite colocar elementos a la izquierda o derecha de su contenedor, aunque puede ser menos flexible que Flexbox o Grid.

Cada una de estas técnicas tiene sus propias ventajas y casos de uso, y es importante elegir la adecuada según las necesidades del diseño y la estructura de la página web.

Media Queries

Las Media Queries son una característica de CSS que permite aplicar estilos específicos en función de las características del dispositivo o la pantalla, como el ancho, la altura, la orientación, entre otros. Esto es fundamental para crear diseños web responsivos que se adapten a diferentes tamaños de pantalla y dispositivos.

Las Media Queries se definen utilizando la regla @media, seguida de una condición que especifica cuándo se deben aplicar los estilos. Por ejemplo:

@media (max-width: 600px) {
    /* Estilos para pantallas pequeñas */
}

En este ejemplo, los estilos dentro de la Media Query se aplicarán solo cuando el ancho de la pantalla sea de 600 píxeles o menos, lo que es común en dispositivos móviles. Esto permite ajustar el diseño y la presentación de la página para mejorar la experiencia del usuario en diferentes dispositivos.

Hover y animaciones

El pseudo-clase :hover en CSS se utiliza para aplicar estilos a un elemento cuando el usuario pasa el cursor sobre él. Esto es comúnmente utilizado para mejorar la interactividad de los elementos en una página web, como enlaces, botones, o cualquier otro elemento que se desee destacar al interactuar con él.

Por ejemplo, para cambiar el color de un enlace cuando el usuario pasa el cursor sobre él, se puede utilizar la siguiente regla CSS:

a:hover {
    color: red;
}

Además de :hover, CSS también ofrece la capacidad de crear animaciones utilizando la regla @keyframes y la propiedad animation. Esto permite definir una serie de estilos que se aplican en diferentes momentos durante la animación, creando efectos visuales dinámicos. Por ejemplo:

@keyframes example {
    from {background-color: red;}   
    to {background-color: blue;}
}
