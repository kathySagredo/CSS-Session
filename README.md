# README - Introducción a CSS

## Descripción

Este proyecto es una introducción práctica a **CSS (Cascading Style Sheets)** utilizando un documento HTML y una hoja de estilos externa.  
El objetivo es comprender cómo CSS permite dar estilo, organizar y mejorar visualmente una página web.

A lo largo del proyecto se explican conceptos fundamentales como:

- Selectores CSS
- Especificidad
- Box Model
- Unidades de medida
- Flexbox
- Grid
- Media Queries
- Hover y animaciones

---

## Estructura del proyecto

```bash
📁 proyecto-css
│── index.html
│── styles.css
```

- `index.html` → Contiene la estructura y contenido de la página.
- `styles.css` → Contiene todos los estilos aplicados al documento HTML.
